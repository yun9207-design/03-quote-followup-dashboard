# 03 견적 후속관리 대시보드

바이브코딩 사업모델 30선의 03번 **견적 후속관리** 실습 앱입니다.

## 해결하려는 문제
월별 견적을 반복 발송하는 소형 B2B 사업자가 **답변 없는 견적·다음 연락일·담당자 할 일**을 놓치지 않도록 돕습니다.

## 실제 동작
- 견적 등록 / 수정 / 삭제
- 발송·대기·응답·수주·실주 상태 관리
- 다음 연락일과 지연일 자동 계산
- 지연·우선순위·금액 기반 후속 큐
- 후속 연락 결과 기록 및 다음 연락일 재설정
- 실습 기준일 변경
- 업체·담당자·태그 검색, 상태 필터
- 응답률 / 종결 기준 수주율 / 진행 금액 통계
- localStorage 자동 저장
- JSON 백업/복원
- CSV 가져오기/내보내기 (날짜는 `YYYY-MM-DD`, 형식이 틀리면 가져오지 않고 해당 행을 알려줌)
- 후속 기록 시 다음 연락일 기본값은 실습 기준일 +3일 (직접 변경 가능, 빈 날짜/잘못된 날짜는 저장 차단)
- 샘플 데이터 초기화

## 의도적으로 제외
- 자동 할인 제안
- 고객 몰래 통화 수집
- 계약 성사 예측 점수
- 무차별 대량 영업 발송
- 최초 문의부터 계약·회계까지의 전체 CRM 대체

## 실행
`index.html`을 브라우저에서 열면 바로 실행됩니다. GitHub에 폴더 전체를 올린 뒤 Vercel에서 정적 사이트로 배포할 수 있습니다.

## 회귀 테스트
`tests/regression.html`을 브라우저에서 열면 자동 실행되고, 맨 위에 통과/실패가 표시됩니다. 가짜 저장소를 쓰므로 실제 앱 데이터는 건드리지 않습니다. (날짜 검증, 후속 기록 기본 날짜, 지연 건수 갱신, 새로고침 유지)
